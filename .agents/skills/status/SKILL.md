---
name: status
description: "Show where each initiative is in the PDLC, what's approved, what's stale, and what's next."
argument-hint: "[slug]"
---

Run `scripts/pdlc status $ARGUMENTS` and show the output in a code block.
Underneath, in no more than four lines, point out anything that needs the PO's attention: drafts waiting for sign-off, artefacts flagged CHANGED SINCE APPROVAL or STALE, and the next command to run.
